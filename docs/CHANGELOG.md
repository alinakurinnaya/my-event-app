# Changelog

Все заметные изменения в проекте документируются в этом файле.

## [0.1.0] - 2026-10-23 

### Added
- Первоначальная настройка проекта (SvelteKit, TypeScript, Tailwind CSS).
- Подключение базы данных SQLite и ORM Prisma.
- Создание схемы данных для сущностей: Event, Participant, Admin.
- Скрипт для генерации тестового ивента (seed).
- Публичная страница ивента (`/event/[id]`) с выводом названия, даты, места и описания.
- Функционал формы записи на ивент с серверной валидацией (имя, email).
- Защита от дублей по email с выводом понятного сообщения об ошибке.

### Fixed
- Устранены конфликты путей при импорте Prisma Client и подключении драйвера `better-sqlite3` в среде WSL.
